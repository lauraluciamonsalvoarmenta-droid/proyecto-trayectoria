# TRAYECTORIA

Laboratorio virtual escolar de movimiento parabólico mediante un saque de voleibol.

Abre index.html en un navegador actualizado para usarlo sin instalación. La guía completa, incluida la publicación con GitHub Pages, está en [GUIA_DE_USO.md](GUIA_DE_USO.md).

Las verificaciones matemáticas se pueden ejecutar con:

    node pruebas/pruebas.js

El modelo es ideal: no incluye resistencia del aire, viento, rotación ni una diferencia entre la altura de salida y llegada.

Verificación: `node pruebas/pruebas.js` (23 pruebas: fórmulas, ángulos complementarios, gravedad y reglas de la cancha).
